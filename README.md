# BIM-Based Adaptive Evacuation Route Assignment
This repository contains the research materials supporting the study
“BIM-Based Adaptive Evacuation Route Assignment Considering Fear Perception and Exit Congestion.”
## Repository contents
- Python code for the proposed framework and time-only routing approach.
- Raw Python-generated output data for Scenarios 2–10 under both routing approaches.
- The Revit building model used in the case study.
- Anonymized individual-level questionnaire responses and a codebook describing the variables and response coding.
## Supplementary Information
The questionnaire instrument and supplementary methodological calculations are provided in the Supplementary Information accompanying the manuscript.
## Data note
Questionnaire data in this repository should contain actual responses only and must not include information that could identify participants.
